## 目标

把本会话已验证的 tokenizer 指纹实验（L1 usage 差分 + L2 官方编码器重建）
产品化为 agent 技能包 endpoint-verify：SKILL.md + scripts/ + registry/ + tests/。

## 安全红线（用户明确要求）

- **任何脚本不硬编码 API key**；key 一律从环境变量读取（如 `--api-key-env DEEPSEEK_API_KEY`）
- `.gitignore` 排除 `.env`、`cache/`、测试产物
- 交付前跑 key 泄漏扫描（grep sk- 模式）

## 任务清单

### T1 骨架 + 资产迁移
- `mkdir scripts registry tests cache`
- 拷贝 `tokenizer-fingerprint/hf-dsv4/encoding_dsv4.py` → `cache/deepseek-v4-flash/`（gitignore）
- 拷贝 `hf-dsv4/tokenizer.json` → `cache/deepseek-v4-flash/`（gitignore）
- 迁移实验数据 → `tests/golden.json`（5 模型 × 10 组 token 序列）

### T2 scripts/probe.py（L1 指纹探测，泛化）
- CLI: `--base-url --api-key-env --model [--prompts-file] [--output]`
- 10 组内置提示词；usage.prompt_tokens 采集；重试；结果 JSON 落盘

### T3 scripts/verify.py（L2 重建 + 三态判定）
- 读 `registry/<model>.json` + `cache/<model>/` 的 tokenizer/编码器
- 配置矩阵（thinking/chat × effort × BOS）本地重建 → 与 API 序列比对
- 判定: 0差=真身 / 恒定差≠0=同族降级(候选矩阵定位) / 波动=跨家族
- 输出判定 JSON

### T4 scripts/fetch_registry.py（指纹库拉取）
- `--model --hf-repo`：HF 拉 tokenizer.json + 编码器 → cache/（断点+hash）

### T5 scripts/report.py
- 判定 JSON → report.md + report.json

### T6 registry 预置条目
- `deepseek-v4-flash.json`：expected_tokens、encode_config(thinking/max/true)、system_prefix_tokens=79
- `deepseek-v3.2.json`：expected_tokens、encode_config(thinking/null/true)（复用 v4 tokenizer，家族共用词表）
- `README.md`（指纹库贡献指南）

### T7 tests
- `run_tests.py`：
  1. 三态判定逻辑单测（构造 0差/恒定差/波动 输入）
  2. v4 本地重建 == golden（缓存完整性）
  3. v3.2 用 v4 编码器 effort=null 重建 == golden（家族复用验证）
- 在线集成（需 key，环境变量注入）：官方 v4-flash=真身、硅基 v3.2=真身/同族、硅基 qwen=跨家族
- key 泄漏扫描

### T8 文档 + 发布文件
- `SKILL.md`（中文）：触发场景、流程、判定规则、key 安全、局限
- `README.md`（英文）：定位、安装、用法、生态对比（claude-detector）、致谢
- `LICENSE`（MIT）、`.gitignore`
